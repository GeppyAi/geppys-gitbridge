# Geppy's GitBridge - Chrome Extension Companion

## 🚀 AI Live Designer & Brainstorm Side Panel

This Chrome extension provides a live, AI-forward companion that docks directly into Google Chrome's native **Side Panel**. You can view your running application in the main browser window (e.g. `http://localhost:5173`, `http://localhost:8080`, `http://127.0.0.1:8000`) while brainstorming and live-editing its code directly in the sidebar.

---

### ✨ Key Features

1. **Auto-Detects Running App**:
   - Matches the URL / Port of the active browser tab to your registered apps in Geppy's GitBridge.
   - Or pick any app in Geppy's App Universe from the header dropdown.

2. **💡 Mode 1: Brainstorm Mode**:
   - Conversational AI creative partner powered by Google Gemini.
   - Proactively suggests design directions, killer features, UX flows, animations, and color palettes.
   - **Real-Time Ideas & Tasks Backlog**:
     - Automatically extracts structured tasks and ideas as you brainstorm.
     - Add custom tasks anytime with `+`.
     - Filter, check off, or click **"⚡ Push to Designer"** to immediately turn an idea into working code!

3. **🎨 Mode 2: Live Designer Mode**:
   - **Proactive AI Design Suggestions**:
     - Evaluates the currently selected code file and suggests 3-4 concrete upgrades (glassmorphism, micro-interactions, responsive flex layout, accessibility).
     - **1-Click "Apply Design"**: Modifies the code in the editor with a single tap.
   - **Backlog Quick-Insert**:
     - Pick any brainstormed task from your backlog and click **"Apply"** to instruct the AI Designer to code it into the file.
   - **Live Code Editor**:
     - Full code editor with line numbers, tab indentation, and unsaved changes tracking.
     - **Ctrl+S / Save**: Directly writes changes back to disk on your local PC.
     - **Reload Tab**: Instantly refreshes the loaded app in your main browser tab so you see the changes live on your screen!

---

### 📦 How to Install in Google Chrome (1-Time Setup)

1. Open Google Chrome.
2. In the address bar, navigate to:
   ```
   chrome://extensions
   ```
3. Enable **Developer mode** toggle in the top-right corner.
4. Click the **"Load unpacked"** button in the top-left.
5. Select this folder:
   ```
   D:\Geppy_Apps\Geppy's GitBridge\extension
   ```
6. The extension **"Geppy's GitBridge - AI Live Designer & Brainstorm"** will appear in your Chrome toolbar!
7. Click the extension icon in your Chrome toolbar to open the **Side Panel**. (You can also pin it to your toolbar for instant access).
